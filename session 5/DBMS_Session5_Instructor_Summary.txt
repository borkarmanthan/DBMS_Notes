═══════════════════════════════════════════════════════
🎯 CORE CONCEPTS TO EMPHASIZE
═══════════════════════════════════════════════════════

  1. FD DEFINITION (the ONE thing they must understand)
     "If X is the same, Y MUST be the same"
     roll_no → name: same roll_no → same name (always!)

  2. TRIVIAL vs NON-TRIVIAL
     Trivial: Y ⊆ X (useless, always true)
     Non-trivial: Y ⊄ X (the ones that matter)

  3. ARMSTRONG'S AXIOMS (must know all 6)
     Primary: Reflexivity, Augmentation, Transitivity
     Derived: Union, Decomposition, Pseudo-Transitivity

  4. ATTRIBUTE CLOSURE ALGORITHM (step-by-step on board)
     X⁺ = X
     Repeat: For each Y→Z, if Y⊆X⁺, add Z
     Until no change

  5. FINDING CANDIDATE KEYS
     Only LHS → must be in key
     Only RHS → never in key
     Both sides → test combinations
     Neither side → must be in key

  6. MINIMAL COVER (3 steps)
     Step 1: Decompose RHS
     Step 2: Remove extraneous LHS attributes
     Step 3: Remove redundant FDs

  7. DECOMPOSITION
     Lossless: R1∩R2 → R1 OR R1∩R2 → R2
     Dependency Preserving: All FDs in individual relations
